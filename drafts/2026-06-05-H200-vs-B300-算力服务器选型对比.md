### 第一章：H200 与 B300 的核心参数对比

| 维度 | NVIDIA H200 | NVIDIA B300 |
|------|------------|------------|
| **架构** | Hopper（H100 升级版） | Blackwell（下一代） |
| **显存容量** | 141GB HBM3e | 192GB HBM3e |
| **显存带宽** | 4.8 TB/s | 8 TB/s |
| **FP8 算力** | ~1979 TFLOPS | ~4000 TFLOPS |
| **FP16 算力** | ~989 TFLOPS | ~2000 TFLOPS |
| **INT8 算力** | ~3958 TOPS | ~8000 TOPS |
| **功耗 (TDP)** | 700W | 1000W |
| **互连** | NVLink 4.0 (900GB/s) | NVLink 5.0 (1800GB/s) |
| **上市时间** | 2024 Q4 | 2025 Q2 |
| **当前供货** | 充足（新机+二手） | 部分紧缺 |

> **数据说明:** 以上为官方标称值，实际性能因系统配置和工作负载而异。H200 为 H100 的高显存版本，B300 为 Blackwell 架构的旗舰产品。

### 第二章：不同场景下怎么选

| 应用场景 | 推荐方案 | 理由 |
|---------|---------|------|
| **大模型训练（70B+ 参数）** | B300 | 更大显存 + 更高带宽，训练速度提升 60-80% |
| **大模型推理部署** | H200 | 性价比更高，推理延迟 B300 仅领先 20-30% |
| **LoRA/QLoRA 微调** | H200 | 141GB 显存足够覆盖大部分微调场景 |
| **RAG 知识库系统** | H200 | 推理密集型，H200 性价比优势明显 |
| **多模态模型** | B300 | 更大显存带宽对视频/图像处理更友好 |
| **科研/教育预算有限** | H200（二手） | 二手价格约为新机 50-60%，性价比极高 |

### 第三章：采购决策框架

#### 算力成本计算
```
总拥有成本 (TCO) = 硬件采购成本 + 电力成本 + 散热成本 + 机房空间成本 + 运维成本
```

以典型 4 卡服务器为例（7×24 运行，电价 0.8 元/度，3 年周期）：

| 成本项 | H200 方案 | B300 方案 |
|-------|----------|----------|
| 硬件（新机，4卡） | ~120-150 万 | ~200-250 万 |
| 电力（3年） | ~55 万 | ~80 万 |
| 散热/机房（3年） | ~18 万 | ~25 万 |
| 运维（3年） | ~15 万 | ~15 万 |
| **3 年 TCO** | **~208-238 万** | **~320-370 万** |

> 注：二手 H200 价格约为新机 50-60%，TCO 可降低至 130-160 万。

### 第四章：二手市场的机会与风险

#### 为什么会有二手 H200/B300？
- 头部云厂商大规模采购后的产能溢出
- 企业升级 B300 后置换下来的 H200
- 数据中心整合产生的闲置资产

#### 二手采购注意事项
1. 选择有检测认证的供应商（进化湾提供检测+质保）
2. 确认卡的使用时长和工况记录
3. 要求提供 burn-in 测试报告
4. 确认质保条款（至少 6 个月）

### 结语

选算力服务器不是"越贵越好"，而是"越适合越好"。H200 和 B300 各有优势场景——关键是在性能需求和预算之间找到最佳平衡点。
